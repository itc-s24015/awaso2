# AI遊びプラン提案

## 詳細
利用者が入力した条件に応じて、アプリ内に用意したルール・テンプレートから遊び方の案を1件ずつ提示する。初版では外部AIサービスや端末内モデルを使用せず、追加のAIライブラリやAI API利用料は発生させない。提案は参考情報として扱い、利用者が確認・編集したうえで企画に反映する。

アプリおよび提案機能に年齢制限を設けない。年齢・生年月日・保護者メールアドレスは取得しない。FR-103のグループ好み学習とは分離し、FR-101の候補選定にはグループの過去の選択履歴を使わない。

## 仕様
### 処理の流れ
1. 利用者が予算、地域、参加人数、興味カテゴリを指定する。地域と興味カテゴリは未選択でもよい。
2. システムは条件に合うテンプレートを抽出する。予算は選択額を1人あたりの上限として扱い、テンプレートの概算上限が選択額以下の場合に候補とする。「特に決めていない」は予算で絞り込まない。
3. 参加人数はテンプレートの対応人数内にあることを条件とする。興味カテゴリを複数選択した場合は、そのうち1つ以上に合うテンプレートを候補とする。興味カテゴリが未選択の場合は興味で絞り込まない。
4. 条件に合うテンプレートから1件をランダムに選び、タイトル、説明、興味タグ、1人あたりの目安予算、所要時間を表示する。予算と所要時間は概算であり、実際の費用・所要時間を保証しない。
5. 「別のアイデアを見る」を選ぶと、現在の提案サイクルでまだ表示していない候補から1件を選ぶ。候補を使い切った場合は、条件の変更を案内する。
6. 条件に合うテンプレートがない場合は、その旨を表示して利用者に条件変更を促す。予算・人数・興味条件をシステムが自動で緩めない。
7. 地域が入力されている場合は「場所を探す」操作から既存の場所検索画面へ引き継げる。場所検索は自動実行せず、実在施設をテンプレートで生成・表示しない。
8. 利用者が提案を企画に使う操作をした場合のみ、企画作成画面に案を引き継ぐ。内容を確認・編集して企画を保存するまで、提案を永続化しない。

### 入出力
|項目|内容|
|---|---|
|1人あたり予算上限|3,000円、5,000円、10,000円、または指定なし。指定額は参加費・利用料の上限として使い、初期値は5,000円。交通費は含めない。|
|行きたいエリア|任意のテキスト入力。テンプレートの選定には使わず、利用者が場所検索へ進むときだけ引き継ぐ。|
|参加人数|2人、3人、4人、5人以上。テンプレートが対応する人数の範囲に入る案だけを候補とし、初期値は4人。「5人以上」の場合は上限人数が設定されていないテンプレートのみを候補とする。|
|興味カテゴリ|自然、食事、体験、のんびり、アクティブから複数選択可能。初期状態では選択しない。|
|提案結果|遊びのタイトル、短い説明、興味タグ、1人あたりの目安予算、所要時間。予算・時間は概算と明記し、実際の費用・所要時間を保証しない。|

### テンプレート項目
テンプレートはアプリ内の静的なデータとして管理し、データベースへ保存しない。初版は5つの興味カテゴリをバランスよく含む10案を目標とする。
以下は初期候補であり、費用・所要時間は検証前の仮の目安である。実際の店舗・施設の料金や受け入れ人数を保証しない。全国一律の価格とは扱わず、概算上限による絞り込みは参考情報として行う。実料金は施設・曜日・特別営業期間などで異なる。たとえば[ラウンドワン公式の店舗別料金表](https://www.round1.co.jp/shop/area01.html)も、利用料金が店舗ごとに異なる旨を案内している。

|項目|内容|
|---|---|
|id|テンプレートを識別する一意の固定ID。|
|title|提案タイトル。|
|description|遊び方や当日の流れの説明。|
|interestTags|自然、食事、体験、のんびり、アクティブから設定するタグ。|
|minParticipants / maxParticipants|対応人数の下限・上限。`maxParticipants`がNULLの場合は上限なし。|
|estimatedCostMinYen / estimatedCostMaxYen|1人あたりの参加費・利用料の概算下限・上限。交通費は含めず、予算照合には上限値を使う。|
|durationMinMinutes / durationMaxMinutes|所要時間の概算範囲。|

### 制御・安全性
- 提案生成はアプリ内のテンプレート照合・選択のみで完結し、外部サービスへデータを送信しない。
- 正確な場所情報、個人情報、会話履歴、過去の個人別・グループ別選択履歴を提案生成に使わない。
- 実在施設の検索は利用者が場所検索へ進み、検索操作を行った場合にのみ既存のFR-008で実行する。Places APIの利用条件・料金はFR-008の要件に従う。
- AI提案を自動的に企画確定しない。利用者が選択した案のみ企画作成画面へ渡す。
