# お気に入り登録

## 詳細
グループメンバーが気になるお店や行き先候補をグループのお気に入りとして登録できる。登録した候補は同じグループの全メンバーが閲覧でき、企画の行き先候補として利用できる。

## 仕様
### 処理の流れ
1. グループメンバーが検索結果または企画候補からお気に入り登録を行う。
2. システムが場所情報をグループのお気に入り一覧に登録する。
3. グループメンバーが一覧を閲覧し、場所の詳細を確認する。
4. お気に入りの候補を企画の行き先に設定できる。

### 入出力
- 入力：グループ識別情報、場所の識別情報、登録者の利用者識別情報。
- 出力：グループのお気に入り一覧、選択した場所の情報。

### 制御・安全性
- グループに参加承認されたメンバーのみ、お気に入りを閲覧できる。
- 同一グループへの同一場所の重複登録を防ぐ。
- お気に入りの削除は、登録者または現在のグループ管理者に限る。

### 外部サービスの扱い
- 永続化するのはGoogle Place IDのみとし、名称・住所などのGoogle Mapsコンテンツは保存しない。
- 検索結果はPlaces APIの応答から必要な項目だけ表示する。保存済みお気に入りの詳細は、利用者が明示的に要求した場合に取得する。
- Google Mapsコンテンツには「Google Maps」の帰属表示を行い、表示内容をアプリ独自の情報と区別する。
- 場所名を含む検索・詳細取得はPlaces APIの課金対象になり得る。無料枠は課金停止の上限ではないため、利用量・料金を監視する。

### 初回実装の範囲
- 検索結果からグループのお気に入りへ登録し、一覧表示・削除する。
- 詳細情報の取得は利用者が明示的に操作した場合に限る。
- お気に入りを企画の行き先候補へ設定する機能は別途実装する。
