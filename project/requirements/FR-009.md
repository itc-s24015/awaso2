# 企画詳細・予定確定

## 詳細
グループメンバー全員が企画内容、日程候補、行き先候補、集計状況を確認できる。日程候補と行き先の両方を設定し、任意のグループメンバーが全員一致を必要とせず予定を確定できる。確定後の予定を編集できるのは企画作成者のみとする。初版では確定後の取消や再投票による再調整を行わず、変更が必要な場合は作成者が確定内容を直接編集する。

## 仕様
### 処理の流れ
1. 利用者がグループ内の企画を選択し、企画詳細を表示する。
2. 詳細画面に企画内容、日程調整の状態、選択可能な行き先を表示する。
3. 任意のグループメンバーが日程と行き先を選択し、全員一致を待たずに確定を実行する。
4. システムが確定した内容を保存し、企画詳細に予定として表示する。
5. 確定後に内容を編集できるのは企画作成者に限る。

### 入出力
- 入力：企画識別情報、確定する日程、行き先、確定操作を行う利用者。
- 出力：確定後の予定情報と更新された企画状態。

### 例外・制御
- 必須情報が不足している場合は確定できない理由を表示する。
- 日程候補または行き先のいずれかが未設定の場合は確定できない。
- グループメンバー以外による確定操作を拒否する。
- 確定に全員一致の合意を必要としない。
- 企画作成者以外による確定後の編集を拒否する。
- 初版では確定後の取消・再投票による再調整を提供しない。予定変更は作成者が確定内容を直接編集する。
- 確定後の内容を変更した場合、現在のグループメンバー全員にアプリ内通知を作成する。Web Pushは利用者が許可・有効化している場合に限り送信する。
