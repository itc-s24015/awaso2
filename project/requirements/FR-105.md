# リマインド通知

## 詳細
日程回答の期限や確定済みの予定など、企画に関する必要な情報を参加者に通知する。参加申請・承認結果の通知方式は[FR-003](./FR-003.md)に従う。Web Pushを利用する場合の送信サービスは別途選定する。

## 仕様
### 処理の流れ
1. 通知対象となる企画イベントまたは期限を設定する。
2. システムが対象グループの参加者と通知設定を確認する。
3. 通知対象とチャネルの設定に従い、通知を許可した利用者へ通知を送る。
4. 利用者が通知から該当企画を開けるようにする。

### 入出力
- 入力：企画識別情報、通知イベント、利用者の通知許可・設定。
- 出力：通知対象、送信結果、対象企画への導線。

### 制御・安全性
- 利用者の許可を得た場合に限りブラウザー通知を送る。
- 通知にグループ内の非公開情報を過剰に含めない。
- 通知送信の重複や、期限後の不要な通知を防ぐ。

### 要確認事項
- リマインド通知の対象（回答期限、予定日時等）と送信時期。
- リマインド通知のチャネルと通知の有効・無効設定。
- HTTPS、Service Worker、対応ブラウザーの範囲。
- 通知の送信処理を実行するサーバー側サービスと費用。
