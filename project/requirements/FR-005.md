# 日程集計・推薦

## 詳細
グループメンバーが任意の開始・終了日時を候補として登録・編集し、参加者から候補ごとに「○（参加可能）」「△（条件次第）」「×（参加不可）」の回答を集める。企画作成者は企画ごとに任意の回答締切を設定できる。締切後、または予定確定後は回答できず、締切が未設定の場合は予定確定まで回答・変更できる。予定確定後の日程候補の編集は企画作成者のみが行う。○の人数を主順位として候補を推薦し、△の人数は別に表示する。同数の候補は同順位とする。個人の予定を自動取得しない。

## 仕様
### 処理の流れ
1. グループメンバーが複数の開始・終了日時候補を登録する。
2. グループメンバーが各日時候補に○・△・×で回答する。
3. 回答をデータベースに保存し、後から同じ利用者が変更できるようにする。
4. システムが候補ごとに回答数、○の人数、△の人数を集計し、未回答のメンバーがいることも表示する。
5. ○の人数が多い順に候補を推薦する。○人数が同じ候補は同順位とし、△の人数は別表示する。
6. 選択された日程を企画詳細に反映し、予定確定機能へ引き継ぐ。

### 入出力
- 入力：企画識別情報、候補日時の開始・終了、回答者、候補ごとの回答。
- 出力：候補ごとの回答一覧、回答数、○人数、△人数、未回答状況、推薦順位。

### 例外・制御
- 回答がない利用者は未回答として扱い、メンバーごとに未回答であることを表示する。
- 候補の追加・変更後に集計結果を更新する。
- 承認済みのグループメンバーは日時候補を追加・編集できる。
- 予定確定後の日程候補を編集できるのは企画作成者に限る。
- 回答者は自分の回答を後から変更できる。
- 企画作成者は回答締切を任意設定できる。設定がある場合、締切日時以降は回答の新規登録・変更を拒否する。
- 締切が未設定の場合は予定確定まで回答・変更できる。予定確定後は回答を変更できない。
- 未回答のメンバーは未回答として扱い、回答を自動補完しない。
- 個人のカレンダーや予定を自動取得しない。
- 日時は閲覧者の端末のタイムゾーン設定に合わせて表示する。
- 入力時刻は入力者の端末のタイムゾーン設定に基づいて解釈し、絶対時刻として保存する。利用者ごとのタイムゾーン設定は保存しない。

### 要確認事項
- 確定後に再調整する際の扱い。
