# グループの好み学習

## 詳細
グループの全メンバーが明示的に同意した場合に限り、アプリ内に通常機能のため保持されている全期間の明示的な採用・見送り履歴を都度集計し、今後の候補を提案する。カテゴリごとに採用を+1点、見送りを-1点としてスコア化し、スコアの高いカテゴリを優先する。学習専用の履歴は別途保存せず、参照元データの保持・削除は通常機能のルールに従う。閲覧やクリックなどの暗黙的な行動履歴は使わない。学習済みの集計データは永続化せず、履歴は外部AIサービスへ送信しない。初版では個人の予定や外部サービス上の個人情報を学習対象にしない。

## 仕様
### 処理の流れ
1. システムが対象グループの全メンバーの明示的な同意を確認する。
2. 全員が同意している場合、システムが対象グループ内の企画結果や選択履歴のみをその都度参照・集計する。未同意のメンバーがいる場合は学習を無効にする。
3. 利用者が新しい企画の候補を求めた際、カテゴリごとに採用+1点・見送り-1点で算出したスコアに基づいて候補を提示する。
4. グループメンバーが候補を採用または見送る。
5. 選択結果を今後のグループ候補の調整に利用する。

### 入出力
- 入力：アプリ内に保持されている全期間の明示的な採用・見送り結果。閲覧・クリック等は含めない。
- 出力：グループの傾向に基づく遊び方や行き先候補。

### 制御・安全性
- グループ単位でデータを扱い、他のグループの履歴を参照しない。
- グループの選択履歴はアプリ内で集計し、外部AIサービスへ送信しない。
- 学習専用の履歴は別途保持せず、参照元データには通常機能の保持・削除ルールを適用する。
- 学習対象とデータ利用について利用者に説明する。
- 新しいメンバーが参加した場合は全員が同意するまで学習を無効にする。同意が撤回された場合も学習を停止する。
- 学習済みの集計データやプロフィールは永続化しない。同意が再び全員分そろった場合は、保持されている元履歴から都度再計算する。
