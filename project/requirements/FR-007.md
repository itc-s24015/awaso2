# 外部地図連携

## 詳細
Google Maps PlatformのMaps Embed APIを利用し、検索結果またはグループのお気に入りから選択した場所を地図上で確認できるようにする。初回実装では一度に1か所を表示し、複数候補のピンを同一地図上で表示する機能は含めない。

## 仕様
### 処理の流れ
1. 利用者が場所検索結果またはグループのお気に入りから「地図で見る」を選ぶ。
2. システムが選択された場所のGoogle Place IDを用いてMaps Embed APIの`place`モードを読み込む。
3. 利用者は地図を操作して場所を確認する。また、必要に応じてGoogle Mapsを別タブで開く。
4. お気に入りから表示する場合もPlace IDのみを使い、地図表示のための追加Places Details API呼び出しは行わない。

### 入出力
- 入力：Google Place IDと画面上で選択された場所の名称・住所。
- 出力：選択中の1か所を示すGoogle Mapsの埋め込み地図と、Google Mapsを別タブで開くリンク。

### 例外・制御
- Maps Embed APIキーが未設定または利用できない場合は、地図が表示できないことを明示し、Google Mapsを別タブで開くリンクを提供する。
- 利用者が候補を明示的に選択した後にのみiframeを読み込み、未選択時はGoogleへ地図リクエストを送らない。
- Place ID以外のGoogle Mapsコンテンツは永続化しない。名称・住所は既存の検索・お気に入り詳細取得の範囲で画面に表示し、地図表示のためにDBへ保存しない。
- Google Mapsの利用条件に従い、埋め込み地図の帰属表示を維持する。iframeは`strict-origin-when-cross-origin`のreferrer policyを設定する。

### 実装設計
- 検索結果およびお気に入りの場所カードに「地図で見る」操作を追加する。選択した場所だけを地図パネルに表示し、選択を切り替えると表示も切り替える。
- Maps Embed APIの`place`モードで、`q=place_id:{Google Place ID}`を指定する。検索結果やお気に入りに既にあるPlace IDを使うため、地図表示のための座標保存や追加Places検索を行わない。
- Maps Embed API用には専用のブラウザーAPIキーを用いる。`NEXT_PUBLIC_GOOGLE_MAPS_EMBED_API_KEY`として設定し、Maps Embed APIだけにAPI制限し、Cloud Consoleで許可したサイトのHTTPリファラーだけから利用できるよう制限する。このキーはブラウザーへ送られる公開キーであり、Places／Geocoding用サーバーキーとは分ける。
- iframeは利用者が「地図で見る」を押したときに初めて描画する。キーが未設定の場合は説明と外部Google Mapsリンクを表示する。
- Maps Embed APIは無料で利用でき、現在の公式資料では短期・長期のリクエスト上限もない。ただしGoogle Cloud Billingを有効にし、利用条件・料金表の更新を確認する。

### 初回実装の範囲
- 場所検索結果・お気に入りから選択した1か所を地図表示する。
- 複数候補の同時ピン表示、地図上のピンからの選択、地図上での候補編集、経路表示は対象外。
- Google CloudでMaps Embed APIを有効化し、ブラウザー用の制限済みAPIキーを設定した後に実地図を確認する。
