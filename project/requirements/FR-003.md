# グループ招待・参加

## 詳細
Googleログイン済みの利用者が、グループ管理者の発行した招待リンクまたはコードを利用して参加申請できる。招待リンクとコードは同じ256-bit乱数トークンを使用し、DBにはSHA-256ハッシュのみを保存する。有効期限は発行から7日間とする。

招待された利用者の参加には、現在のグループ管理者の承認が必要である。申請中の利用者はグループメンバーとして扱わず、承認後にのみグループ情報を閲覧できる。画面は暗い背景と高いコントラストを持つ既存のアプリテーマに従う。

## 仕様
### グループ招待画面
- 選択中のグループ名、招待リンク、QRコード、招待コードを表示する。
- 現在のグループ管理者のみが招待情報を発行できる。
- 招待リンクとコードは同一の64桁16進トークンとする。平文トークンは発行時のみ画面上で扱い、DBにはハッシュだけを保存する。
- 招待リンクは`/invite/{token}`形式とする。QRコードはこのリンクから生成する。
- 招待リンクをクリップボードへコピーする。Web Share APIが利用できる場合は外部共有も提供する。
- 招待の有効期間は発行から7日間。新規申請は期限後に受け付けない。

### グループ参加画面
- 招待リンクまたは入力された招待コードを検証し、対象グループ名と招待の有効状態を表示する。
- 無効・期限切れの招待は申請できず、エラーを表示する。
- 未認証の場合、Googleログインへ誘導し、認証後に招待画面へ戻る。
- 認証済みでもニックネームが未登録の場合、ニックネーム設定画面へ誘導する。Googleプロフィール名を自動保存せず、利用者の確定後にプロフィールを作成する。
- 利用者が参加を確認すると参加申請を登録する。申請中・拒否後はグループデータを閲覧できない。
- 既にメンバーの場合は参加状態とグループ詳細への導線を表示し、重複登録しない。
- 同一グループに申請中の申請が既にある場合は重複申請を作らず、その申請状態を表示する。
- 参加申請が承認された後、利用者はグループ詳細へ進める。

### 管理者の承認・通知
- 現在のグループ管理者に申請中の一覧を表示し、承認または拒否できる。
- 承認・拒否は判断時点でのグループ管理者のみ実行できる。
- 申請受信は管理者へ、承認・拒否結果は申請者へアプリ内通知として記録し、通知一覧に表示する。
- Web Pushは利用者が許可し対象通知を有効化している場合に限るが、送信方式未決のため今回は実装対象外とする。
- 期限前に受け付けた申請は招待期限後も判断可能とする。初版では招待・申請の手動取消機能を設けない。
