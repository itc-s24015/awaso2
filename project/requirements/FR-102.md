# 遊びガチャ

## 詳細
遊び方や行き先の候補からランダムに案を提示し、グループが企画を始めるきっかけを提供する。

## 仕様
### 処理の流れ
1. 利用者が遊びガチャを実行する。
2. システムが利用可能な候補から1件以上をランダムに選ぶ。
3. 選んだ候補を表示し、利用者が採用または引き直しを選べるようにする。
4. 採用された候補は企画作成に引き継げる。

### 入出力
- 入力：ガチャ実行要求。必要に応じて利用者が指定する条件。
- 出力：ランダムに選ばれた遊び方または行き先候補。

### 要確認事項
- 候補データの提供元と更新方法。
- AI提案の候補を抽選対象に含めるか。
- 一度表示した候補を除外するか、引き直し回数を制限するか。
