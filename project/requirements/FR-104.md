# 思い出アルバム

## 詳細
グループの企画ごとに写真や思い出を保存し、企画に参加したグループメンバーが閲覧できるようにする。

## 仕様
### 処理の流れ
1. グループメンバーが企画のアルバムを開く。
2. 利用者が写真または思い出の内容を登録する。
3. システムが企画に紐付けて保存し、権限のあるメンバーに表示する。
4. 権限のある利用者が登録内容を削除できる。

### 入出力
- 入力：企画識別情報、画像ファイル、任意の説明文。
- 出力：企画ごとの写真・思い出一覧。

### 制御・安全性
- グループメンバー以外がアルバムを閲覧できないようにする。
- 画像の保存容量やファイル形式を制限する。

### 要確認事項
- 画像の最大サイズ・形式・枚数、保存期間と保存先。
- 写真の追加・削除を行える権限と、企画削除時の扱い。
- 他の利用者が写る写真の掲載に関する注意表示。
