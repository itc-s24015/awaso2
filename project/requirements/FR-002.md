# グループ作成・管理者移譲

## 詳細
利用者が予定調整用グループを作成し、作成者をグループ管理者として扱う。管理者が退会する場合、他のメンバーがいれば在籍期間が最も長いメンバーへ管理者を自動で移譲する。在籍日時が同じ場合はユーザーIDの昇順で決定する。ほかにメンバーがいない場合はグループを削除する。

## 仕様
### 処理の流れ
1. Googleログイン済み利用者がグループを作成する。
2. 作成者はグループ管理者として登録される。
3. 管理者が退会する場合、他のメンバーのうち在籍期間が最も長いメンバーへシステムが管理者を自動で移譲する。在籍日時が同じ場合はユーザーIDの昇順で決定する。
4. 作成者以外にメンバーがいない場合、システムがグループとそのグループに紐づくデータを削除する。

### 入出力
- 入力：グループ名、作成者の利用者識別情報、退会操作。
- 出力：作成されたグループ、管理者移譲結果、または削除結果。

### 制御・安全性
- グループには管理者を1名設定する。
- 移譲候補は`joined_at`が最も早いメンバーとし、同時刻なら`user_id`の昇順で決定する。
- 管理者移譲後も、グループメンバーの閲覧・操作権限を適切に維持する。

### 要確認事項
- 作成者が退会する際の確認画面・移譲通知。
- 最後のメンバーが退会する場合に削除する関連データの範囲。
