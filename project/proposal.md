# 友達との予定決めを簡単にするアプリ「あわそ」企画書

## 企画の目的
友達同士で遊びの予定を決める際に発生する、日程調整や行き先探しの手間を減らし、参加者全員が予定を決めやすくすることを目的とする。

## 企画の概要
「あわそ」は、専門学校生や大学生が友達とグループを作り、遊びの企画、候補日、行き先をまとめて相談できるアプリである。参加者の日程を集計して候補日を推薦し、お店や駐車場を地図と連携して探せるようにする。企画の詳細を共有し、決定した予定を参加者間で確認できるようにする。

## ターゲット
- 友達と遊ぶ予定を立てる機会が多い専門学校生・大学生
- 複数人での日程調整や行き先探しに手間を感じているグループ

## 企画の詳細

### 必須機能
- **ニックネーム設定**：利用者がアプリ内で表示するニックネームを設定する。同じニックネームの利用を許可する。
- **グループ作成**：友達との予定調整に使うグループを作成する。管理者が退会する場合、他のメンバーがいれば在籍期間が最も長いメンバーへ管理者を自動で移譲する。在籍日時が同じ場合はユーザーIDの昇順で決定し、他のメンバーがいなければグループを削除する。
- **グループ招待・参加**：Googleログインした利用者が招待リンクまたはコードから参加を申請し、現在のグループ管理者の承認後に参加できるようにする。招待の有効期限は7日間とし、期限後は新規申請を受け付けない。期限前に受け付けた申請は管理者が判断するまで自動失効せず、招待期限後も承認できる。申請と承認・拒否の結果はアプリ内通知として記録し、Web Pushは利用者が許可・有効化した場合に限り送信する。初版では招待・参加申請の手動取消機能を設けない。
- **企画作成**：グループ内で遊びの企画を作成し、内容を共有する。
- **日程集計・推薦**：グループメンバーが任意の開始・終了日時を候補として登録・編集し、メンバーが「○（参加可能）」「△（条件次第）」「×（参加不可）」で回答する。企画作成者は任意の回答締切を設定でき、締切後は回答の新規登録・変更をできない。締切が未設定の場合は予定確定まで回答・変更できる。予定確定後の日程候補の編集は企画作成者のみが行う。○の人数を主順位として推薦し、△の人数は別表示する。同数の候補は同順位とする。個人の予定を自動取得せず、日時は閲覧者の端末設定に合わせて表示する。
- **お気に入り登録**：気になるお店や候補をグループのお気に入りとして保存し、メンバー間で共有する。削除は登録者または現在のグループ管理者が行える。
- **外部地図連携**：Google Maps Platformと連携し、地図上で場所を確認できるようにする。
- **企画詳細・予定確定**：企画の内容や決定事項を確認し、日程候補と行き先の両方を設定して、任意のグループメンバーが全員一致を必要とせず予定を確定できるようにする。確定後の編集は企画作成者のみが行い、変更時は全メンバーへアプリ内通知を作成する。Web Pushは許可・有効化済みの利用者に限る。
- **お店・駐車場の検索**：Google Maps Platformを利用し、日本国内を対象に、自由入力のキーワードと「お店」「駐車場」の検索対象、利用者が入力した地域または許可を得た端末の現在地から検索できるようにする。検索半径は5km・10km・20km・50kmから選び、10kmを初期値とする。結果には名称・住所・距離・地図位置を表示する。営業時間・評価を表示するかは費用確認後に決定する。駐車料金・空き状況は保証せず、外部由来の詳細情報は永続化しない。
- **アカウント・関連データ削除**：利用者がアカウントを削除できる。本人のプロフィール、作成した企画、投稿した写真、企画に紐づく本人の回答を削除する。グループ管理者の場合は上記ルールで管理者を移譲し、他のメンバーがいなければグループを削除する。

### 初版に含める追加機能
- **AI遊びプラン提案**：利用者が入力した条件に応じた遊び方や行き先の案を提示する。
- **遊びガチャ**：遊び方や行き先の候補をランダムに提示する。
- **グループの好み学習**：グループの過去の選択などをもとに候補を提案する。
- **思い出アルバム**：企画ごとの写真や思い出を保存・共有する。
- **リマインド通知**：予定や回答期限などを参加者に知らせる。

### 今後の追加を検討する機能
- **予定変更時の再調整**：予定変更があった際に、日程の再調整を支援する。

### 利用の流れ
1. 利用者がGoogleログインし、ニックネームを設定してグループを作成するか、招待から参加申請する。
2. グループ管理者が参加申請を承認し、グループ内で企画を作成する。
3. 参加者が候補日時に回答する。個人のカレンダーから予定を自動取得しない。
4. 回答を集計して日程候補を確認し、お店や駐車場などの行き先を探す。
5. 企画の詳細を共有して予定を確定し、必要に応じて写真や思い出を保存する。

### 画面デザイン
暗めの背景色を基調とし、文字色は背景上で読みやすい明るい色にする。重要な操作や選択中の項目は、背景と十分なコントラストを持つ色で区別する。

## 環境・技術要件
- **開発環境**：本リポジトリの既存環境を利用し、パッケージ管理にはpnpmを使用する。現在の構成はNext.js 16.4.6、React 19.3.0、TypeScript 5、Tailwind CSS 4.3.3である。
- **基本構成**：既存のNext.js/TypeScriptを継続する。データベースとリアルタイム共有にはSupabase（PostgreSQL）を採用し、ログインにはSupabase Auth経由のGoogle OAuthを利用する。地図・場所検索にはGoogle Maps Platformを利用する。以下は調査時点（2026年11月25日）の情報であり、実装前に最新の仕様・料金・規約を確認する。
- **データベース・認証**：
  - SupabaseはPostgreSQLを中心に、認証、ファイル保存、Realtimeをまとめて利用できる。グループ、企画、候補日、回答、お気に入りなど、関連するデータを扱う本アプリのデータベースとして採用する。[Supabase Realtime](https://supabase.com/docs/guides/realtime)
  - Supabaseの無料プランはDB 500MBなどを含む一方、1週間非アクティブなプロジェクトは停止する。Proは月額25米ドルから。料金と制限は[公式料金表](https://supabase.com/pricing)を参照する。
  - Googleログインで利用者を識別し、ニックネームを表示名として設定する。招待承認の状態に基づくメンバーごとの閲覧・編集権限を定義し、SupabaseのRow Level Security（RLS）等でデータアクセスを制御する。
- **地図・お店・駐車場検索**：
  - Google Maps Platformは、Maps Embed APIによる選択場所の地図表示とPlaces APIによる場所検索を提供する。[Maps Embed API](https://developers.google.com/maps/documentation/embed/embedding-map)・[Places API](https://developers.google.com/maps/documentation/places/web-service/overview)
  - Maps Embed APIは調査時点で無料、リクエスト数の短期・長期上限なし。Places検索・Geocodingなどは別SKUで課金される可能性があるため、使うAPIごとに見積もり、利用上限や予算アラートを設定する。[Google Maps Platform料金](https://developers.google.com/maps/billing-and-pricing/pricing)
- **位置情報**：端末の現在地から検索する場合は利用者の許可を得る。拒否または取得失敗時には、利用者が地域を入力して検索できるようにする。
- **通知（初版対象）**：参加申請・承認結果はアプリ内通知として記録し、Web Pushは利用者の許可・設定がある場合に限り送信する。Firebase Cloud Messaging（FCM）はWeb Pushの候補であり、採用は未決定。Web PushにはHTTPS、Service Worker、利用者の通知許可が必要となる。[FCM Web設定](https://firebase.google.com/docs/cloud-messaging/web/get-started)
- **AI提案（初版対象）**：年齢・生年月日・保護者メールアドレスは取得しない。外部AIや端末内モデルは使わず、アプリ内のルール・テンプレートから条件に合う案を1件ずつ提示する。実在施設は自動検索せず、利用者が希望した場合のみ既存の場所検索へ進む。提案は参考情報として表示し、利用者が選んだ案だけ企画作成へ引き継ぐ。
- **ホスティング**：Next.jsと親和性の高いVercelをデモ公開の候補とする。調査時点の料金はHobbyが月額0米ドル、Proが月額20米ドル。[Vercel料金](https://vercel.com/pricing)・[Next.js対応](https://vercel.com/docs/frameworks/full-stack/nextjs)。ただし、現行規約にはHobbyプラン等でコンテンツがAI学習に利用される可能性が記載されているため、利用者の情報を扱う場合は規約とデータの扱いを確認し、適切なホスティングプランを選ぶ。[Vercel利用規約](https://vercel.com/legal/terms)
- **開発の優先順位**：初版ではMust機能に加え、AI遊びプラン提案、遊びガチャ、グループの好み学習、思い出アルバム、リマインド通知を対象とする。予定変更時の再調整は後続候補とする。Google Maps Platformの検索品質・費用、およびAI・写真保存のデータ取扱いを実装前に確認する。
